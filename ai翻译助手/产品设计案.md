# AIリアルタイム会話サポートアプリ 产品设计案

## 产品名称

中文暂定名：AI翻译助手

候选名称：

- AI会話サポートアプリ
- Meeting Mate AI
- リアルタイム会議アシスト
- AI応答サポーター

## 背景与问题

用户在日语听课、会议、面谈或日常对话中，经常会遇到被提问的情况。即使大概听懂了对方的意思，也可能因为日语表达不够熟练，无法马上组织出自然、合适的回答。

尤其在线上会议或课堂中，对方提问后通常需要快速回应。反应过慢会增加沟通压力，也容易让用户错过表达机会。

## 产品目标

帮助日语能力不够流利的用户，在会议、授课、面谈等场景中快速理解对话内容，并生成简单、自然、高效的日语回答。

核心解决三个问题：

- 听不懂或来不及理解日语内容
- 被提问时不知道如何回答
- 对话结束后难以整理重点内容

## 典型使用场景

### 线上会议

用户用电脑参加日语会议，电脑扬声器播放会议声音。用户把 iPhone 放在电脑旁边，App 通过手机麦克风接收会议声音。

App 自动将日语语音转换成文字，并翻译成中文。当用户点击“帮我回答”时，系统根据当前内容和会话设定生成日语回答。

### 课堂听讲

用户听老师讲课时，App 实时记录日语内容并翻译成中文。如果老师突然提问，用户可以快速生成一个简短回答。

### 面谈或工作沟通

用户提前创建会话并设置回答方向，例如：

- 我想表达自己正在努力学习
- 我希望回答得简单自然
- 我想表现出积极性
- 我不想回答得太复杂

AI 会根据这些要点生成更符合用户情况的回答。

## MVP 功能范围

第一版先降低实现难度，暂不强制做全自动提问检测，采用“用户手动点击帮我回答”的方式。

- 创建和编辑会话
- 设置用户身份、会议背景、AI 回答要点
- 设置回答长度：短、普通、详细
- 设置回答语气：自然、礼貌、商务
- 使用 iPhone 麦克风接收日语语音
- 日语语音转文字
- 中文翻译展示
- 用户点击“帮我回答”
- AI 生成简单日语回答
- 保存本次会话重点
- 生成会后总结

## ChatGPT API 接入原则

OpenAI API Key 不应该直接写在 iOS App 中，应该放在服务器端管理。App 只请求自己的后端服务。

建议接口：

- `POST /api/translate`
- `POST /api/answer`
- `POST /api/summary`

请求 `answer` 接口时建议携带：

- 当前场景
- 用户身份
- 回答语言
- 回答长度
- 回答风格
- 当前对话内容
- 用户预设回答要点

## 风险与对策

| 项目 | 风险 | 对策 |
| --- | --- | --- |
| 语音识别准确性 | 环境吵、多人数同时说话时识别变差 | 使用外放靠近手机，后续增加降噪和分段处理 |
| 回答速度 | 会议中需要快速回答 | 第一版回答保持简短，后端接口做流式返回 |
| 隐私问题 | 会议可能包含个人或公司信息 | 明确提示用户，支持删除历史，不默认保存录音 |
| API 密钥 | Key 泄露会产生安全和费用风险 | Key 只放服务器端，App 不内置 Key |
| 使用许可 | 会议或课堂录音可能需要许可 | App 首次使用时加入合规提醒 |

## 一句话产品介绍

本产品通过 iPhone 麦克风获取日语会议音声，并结合语音识别、翻译和 ChatGPT API，实现实时理解、AI 回答生成以及会话总结功能，帮助日语能力不足的用户更自然地参与会议和课堂交流。

## 日语版简短介绍

本アプリは、日本語での授業や会議に不安を感じる外国人をサポートするAI会話支援アプリです。スマートフォンのマイクで会話音声を取得し、リアルタイムで文字起こしと翻訳を行います。また、相手から質問された場合には、ChatGPTを利用して、簡単で自然な日本語の回答案を生成します。さらに、会話ごとにAI回答の方針を設定したり、会話終了後に内容を自動でまとめたりすることもできます。
