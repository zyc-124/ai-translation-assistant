
一，创建数据库 
    1，语法：CREATE DATABASE test DEFAULT CHARACTER SET utf8
    
        CREATE DATABASE ------创建数据库关键字
        test            ------数据库名称
        DEFAULT CHARACTER SET --指定的默认编码类型
        utf8            ------指定编码

    2，查看数据库：show databases
二，删除数据库
    1，DROP DATABASE TEST

        DROP DATABASE   ------删除数据库关键字
        TEST            ------数据库名称 
三，数据类型（m表示显示长度，只有设置zerofill的时候才有用，）
    1，整数类型
        tinyint(m)      ------1个字节（最常用）
        samallint(m)    ------2个字节
        mediumint(m)    ------3个字节
        int(m)          ------4个字节(最常用)
        bigint(m)       ------8个字节
    2，浮点类型
        float(m,d)      ------单精度浮点型，m总个数，d小数位
        double(m,d)     ------双精度浮点型，m总个数，d小数位
    3，字符类型
        char(n)         ------固定长度，n表示不够时用n补齐
        varchar(n)      ------可变长度
        text            ------不设置长度
    4，日期类型
        date            ------日期格式：YYYY-MM-DD
        time            ------日期格式：HH:MM:SS
        datetime        ------日期时间格式：YYYY-MM-DD HH:MM:SS
        timestamp       ------时间戳：YYYYMMDD HHMMSS
